# Customer-Relationship-Management
A centralized web application to manage customer data, track interactions, monitor sales activities, and improve business relationships. It helps streamline workflows and provides insights through organized customer records and reports.
This CRM system provides a centralized dashboard for managing customer information, monitoring sales activities, and enhancing business relationships. It improves efficiency by organizing customer data, tracking interactions, and generating insights that help businesses make informed decisions.

## 📦 Installation & Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/GOKUL-sketch-coder/Customer-Relationship-Management.git
Import the database:
Open phpMyAdmin
Create a new database (e.g., crm_system)
Import the SQL file: crm_database.sql

Update database config:

// in includes/config.php
$servername = "localhost";
$username = "root";
$password = "";
$dbname = "crm_system";
Run the project in a local server (e.g., XAMPP, WAMP)
